# QA Manual Testing Portfolio

## 📌 Overview

This repository contains my Manual Testing work, including test cases and testing documentation for different application modules. The projects demonstrate my understanding of functional testing, positive and negative testing, validation, role-based access control, and end-to-end business workflows.

## 📂 Projects

### 1. E-Commerce Testing

Test cases created for validating major E-Commerce workflows and functionalities.

**Areas Covered:**
- Product listing and product details
- Product search and selection
- Cart management
- Add/Remove products
- Quantity and price validation
- Checkout process
- Payment workflow
- Order placement
- Order-related validations
- Positive and negative scenarios

**Use Case:**
The E-Commerce module allows customers to browse products, add products to the cart, proceed to checkout, make payments, and place orders. Testing was performed to verify that these workflows function correctly and provide a reliable user experience.

📄 **File:** `Ecom Testcases - Sheet1.pdf`

### 2. LMS – Lead Management System

Test cases created for validating the Lead Management System and its lead management workflows.

**Areas Covered:**
- Lead creation
- Lead information validation
- Lead assignment
- Lead status management
- Lead updates
- Follow-up workflows
- Lead tracking
- Positive and negative scenarios

**Use Case:**
LMS is used by sales teams to manage potential customers throughout the lead lifecycle. It helps users create, assign, update, track, and manage leads from initial enquiry to conversion.

📄 **File:** `LMS - Sheet1.pdf`

---

### 3. RBAC – Role-Based Access Control

Test cases created for validating role-based permissions and access control.

**Roles Covered:**
- Partner
- Senior Receptionist / Manager
- Stylist
- Financial Consultant

**Areas Covered:**
- Booking management
- Create bookings and assign stylists/artists
- Edit staff assigned to bookings
- Cancel/Delete bookings
- Payment adjustment
- Adding dues during checkout
- Settling customer dues
- Permission-based access
- ALL permissions
- CREATED_ONLY permissions
- CREATED_OR_ASSIGNED permissions
- Positive and negative authorization scenarios

**Use Case:**
RBAC controls access to application features according to the user's assigned role and permissions. Testing ensures that authorized users can perform permitted actions while unauthorized users are restricted from accessing or modifying protected features.

📄 **Files:**
- `RBAC - Sheet1.pdf`
- `RBAC.xlsx`
